# 경조사비 계산기 — 구현·검증 이력

검토일: 2026-10-04 (Asia/Seoul)

## 적용

- 예정 경조사 최대 50건과 선택 예산을 계산한다. 종류별 건수, 유효 금액 합계, 예산 잔액·부족액을 표시한다.
- 미입력·범위 밖 금액이 있는 합계는 불완전함을 표시하며, 남은 예산으로 확정하지 않는다.
- 월은 한국 시간으로 초기화한다. 이름·행사는 선택 입력이고, 기록 연결 없이 이용할 수 있다.
- 각 행사에서 금액 가이드로 이동해 선택한 금액을 해당 행에 적용한다. 기존 계획·예산은 유지한다.
- 예정 내용은 현재 앱 이용 중에만 유지하며 실제 기록·합계·DB에는 저장하지 않는다. 새로고침·종료 시 초기화됨을 화면에 알린다.
- TDS 버튼·금액 입력, 공식 토스 뒤로가기, 일반 브라우저의 돌아가기, CSR·lazy 페이지를 사용한다.

- Gate 1 PASS: `tsc -b`, 린트, 테스트 39개 통과(기존 에뮬레이터 테스트 1개 제외), SDK 3.x 빌드 성공, 신규 any 0개, diff 공백 검사 통과.
- Gate 2 PASS: dist 1,668 → 1,676 KiB (+0.48%). 신규 의존성 없음. 최대 50건 계산과 가이드 연결은 로컬 상태에서 수행하며 새 네트워크 요청을 만들지 않음.
- Gate 3 컨벤션 4/5: pages→components→hooks→apis의 타입·계산 규칙 분리. Action: 서버 호출 없는 로컬 계산으로 구현.
- Gate 3 사용자 흐름 4/5: 브라우저에서 계산기 진입, 예산 입력, 가이드 이동·금액 적용 후 기존 예산 유지 확인. Action: 앱인토스 실기기 뒤로가기·키보드·작은 화면 검증은 출시 전 수행.
- Gate 3 상태 관리 4/5: MainPage에 연결된 hook이 화면 왕복 중 입력을 유지하며, 기존 기록 store에는 쓰지 않음. Action: 행별 금액 적용·삭제 및 불완전한 합계 처리를 테스트.
