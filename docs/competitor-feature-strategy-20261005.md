# 마음 마을 제거와 경쟁 서비스 기반 기능 전략

검토일: 2026-10-05. 공식 소개 및 개발자가 작성한 스토어 설명을 확인했다. 실제 설치·가입·유료 기능을 사용한 평가는 아니다. 소개 페이지의 기능 존재와 사용성 평가는 구분한다.

## 적용 내용

사용자 요청으로 마음 마을 페이지, 메인 진입점, 지도/집 CSS, 꾸미기 저장 로직과 전용 테스트, 분석 이벤트 타입을 제거했다. 기존 보낸/받은 경조사 기록, 메인 카드 3열, 경조사 도구 3페이지의 모바일 스크롤 수정은 유지한다. 기존 기기 내 마을 꾸미기 설정은 더 이상 읽지 않으며 실제 장부 데이터를 삭제하지 않는다. 과거 검증 문서는 이력으로 보존한다.

## 대체 기능 우선순위

아래는 확인된 경쟁 기능을 바탕으로 제안한 자체 기획이다. 아직 구현하지 않았으며 경쟁사가 모두 제공한다는 뜻이 아니다.

### 1. 청첩장·부고 붙여넣기 → 경조사 준비 카드 (우선 추천)

받은 문자 텍스트를 붙여넣으면 이름·날짜·시간·장소를 후보로 추출한다. 사용자가 수정하고 확인한 다음 행사 준비 카드로 저장한다. 카드에는 기존 해당 인물 기록, 봉투 준비, 축하/위로 메시지 복사, 행사 후 실제 금액 기록 진입을 함께 둔다.

- 새 가치: 기억해서 직접 입력하는 장부에서, 실제로 받은 초대 메시지로 시작하는 도구로 확장.
- 무료 구현 범위: 브라우저 내 규칙 기반 텍스트 추출. 외부 AI 호출과 초대장 링크 자동 수집은 하지 않는다. 애매한 값은 비우거나 후보 표시하고 확인을 필수로 둔다.
- 다음 결정: 일정 데이터 저장 방식. Firestore 구조를 바꾸는 구현은 범위 확정 후 진행한다.
- 유입 가설: 검색/공유에서 이해하기 쉬운 '청첩장 문자 정리'라는 사용 이유가 생긴다. 신규 사용자 증가를 보장하지 않으며 실제 유입 경로·전환 측정이 필요하다.

### 2. 봉투 작성 미리보기 + 감사/축하 카드 만들기

종류와 이름·소속을 고르면 실제 봉투 앞뒷면 위치를 보여 준다. 별도 화면에서 짧은 축하·위로·감사 문구를 편집하고 이미지 카드로 저장하거나 사용자가 직접 공유한다. 기존 서비스의 귀여운 톤은 이 출력물에서 살린다.

- 무료 구현 범위: 자체 문구 템플릿, SVG/Canvas 이미지 생성. 생성형 AI·결제·보상 없이 가능.
- 유입 가설: 유용한 결과물에 작은 서비스 이름과 사용자가 선택한 링크를 넣으면 자연스러운 소개 경로가 될 수 있다. 상대방 이름/금액/관계는 자동 공개하지 않는다.
- 앱인토스의 파일 저장/공유 지원 및 정책은 구현 전 공식 문서에서 확인한다. 자동 문자·푸시 발송은 하지 않는다.

### 3. 종이 장부·봉투 사진에서 기록 초안 만들기 (실험 후보)

이름·금액 여러 줄을 추출하고 사용자가 원본과 대조한 뒤 개별 확인하여 저장한다. 현장 입력 시간을 줄이는 목적이다.

- 가장 큰 새 가치: 기존 종이 장부를 한 번에 옮기는 문제 해결.
- 제약: 한국어 손글씨 OCR 정확도, 기기 성능, 모델 다운로드 크기. 무료·온기기 OCR의 실효성을 먼저 실험해야 한다. AI API 비용 없이 정확한 자동화를 보장하지 않는다.
- 잘못 읽은 금액을 자동 저장하지 않는다. 사진을 외부 서버에 전송하는 구현은 현재 범위에 포함하지 않는다.
