# 인앱 배너 연동 준비 — 2026-10-05

## 적용 범위

- 메인 기록 목록과 스와이프 안내 아래, 서비스 안내 위에 한 개 배치. 고정·겹침·기록 카드 변형 없이 문서 흐름 안에서 표시한다.
- 광고 SDK 표준 expanded/grey/auto 프리셋만 사용하며 Ad 라벨·CTA·글꼴을 수정하지 않는다. 컨테이너는 100% 폭, 최소 높이 96px, 상하 32px 간격이다.
- 기록 입력·금액 입력·사용법 안내·약관·개인정보 안내·보조 기능 화면에서는 슬롯을 제거한다. 광고 터치가 기록 스와이프에 전파되지 않는다.
- 일반 브라우저, 미지원 SDK, 실패·No Fill에서는 광고 영역을 제거한다. 화면 종료 및 초기화 도중 화면을 떠난 경우도 슬롯을 정리한다.
- SDK 초기화는 한 번이며, 자동 재요청 타이머·클릭 유도·보상·성과 이벤트 조작이 없다. 이름·금액·날짜·관계·CSV는 광고 API 인자로 전달하지 않는다.
- 신규 의존성, Firestore 규칙·스키마·인증·금액 계산 변경 없음.

## 설정과 현재 상태

`VITE_BANNER_AD_MODE` 미설정 또는 `off`: 광고 없음. 현재 생성한 운영 번들도 이 상태다.

`test`: `ait-ad-test-banner-id`만 사용한다. `VITE_BANNER_AD_GROUP_ID`가 있어도 무시한다. 테스트용 번들은 예를 들어 `VITE_BANNER_AD_MODE=test npm run build`로 별도로 만들고 토스 앱에서 확인한다. 실사용 버전으로 출시하지 않는다.

`live`: 운영 빌드와 실제 배너 그룹 ID가 모두 필요하다. DEV와 QA에서는 실제 광고를 요청하지 않는다. 토스 콘솔 → 인앱 광고 → 광고 유형 배너 → 광고 그룹 `메인_하단_배너`로 등록 후 발급된 ID를 설정해야 한다. 기존 광고가 없음을 확인했으며 아직 그룹 생성·운영 활성화·업로드·출시는 하지 않았다.

사업자등록을 계속 하지 않으려는 사용자 조건 때문에 실제 광고 활성화 범위를 질문한 상태다. 5천 원 유예 한도를 클라이언트에서 자동 확인·차단하는 기능은 구현하지 않았다. 광고를 중단하면 유예 정책에 따른 서비스 노출 중단을 무조건 피할 수 있다고 보장하지 않는다. 실업급여 영향 역시 이 정책만으로 판단하지 않는다.
