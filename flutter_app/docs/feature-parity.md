# 기존 미니앱 기능 대응표

기준: 현재 저장소의 React 페이지·컴포넌트·hook. Flutter는 독립 로컬 앱이라는 기존 합의에 따라 사용자 기능을 재구현합니다. 동일한 TDS 자산·픽셀 배치·애니메이션을 복제하는 작업은 아닙니다.

## 독립 앱에 맞춘 차이

- 토스 식별자·브리지·Firebase Auth/Firestore·토스 Analytics는 사용하지 않습니다. SQLite/OS API로 대체하며 토스 데이터 연동은 없습니다.
- 로컬 DB는 전체 기록을 읽으므로 원격 페이지네이션·연결 대기 UI는 필요하지 않습니다. DB 조회 실패 재시도와 쓰기 실패는 처리합니다.
- TDS 전용 캐릭터와 아이콘 대신 공식 공개 라이선스의 토스페이스 원본 폰트와 기본 아이콘을 사용합니다. 정확히 같은 캐릭터가 아닌 15개 이모지입니다. 기존 8종 이모지도 폰트로 표시합니다.
- 온보딩은 같은 ‘추가 → 모드 전환’ 설명을 순서대로 보여주는 대화상자입니다. 기존 화면 강조 마스크와 코인 축하 애니메이션은 복제하지 않았습니다.
- 기존 기록의 중요 표시는 편집 중에도 즉시 저장하고 실패 시 되돌립니다. 새 기록은 초안에 적용한 뒤 기록 저장 시 확정합니다. 카드/목록의 즐겨찾기도 즉시 저장합니다.
- 총액은 미니앱의 만원 단위 절삭 대신 정확한 원 단위로 표시합니다.
- 장부는 CSV를 단순 미리보기로 끝내지 않고 편집 가능한 입력 목록에 합칩니다. 저장해야 실제 기록이 됩니다.
- 원본 카드 3열을 기본으로 하되 좁은 화면은 2열로 표시합니다.
- 일반 기록 날짜 선택 UI는 기존처럼 ±10년입니다. 장부 날짜 선택 UI는 1900~2200년을 지원합니다.
