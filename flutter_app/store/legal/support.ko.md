## 자주 묻는 질문

### 토스 로그인이나 회원가입이 필요한가요?

필요하지 않습니다. 독립 앱은 로그인 없이 사용할 수 있습니다. 앱인토스 계정이나 토스 식별자와 연결되지 않습니다. 계정이 없으므로 별도의 회원 탈퇴 절차도 없습니다.

### 앱인토스에서 쓰던 기록이 자동으로 나오나요?

아니요. 앱인토스 버전과 독립 앱은 별개로 동작합니다. 기존 토스 기록을 자동으로 가져오거나 양쪽 앱을 동기화하지 않습니다.

### 인터넷 없이 사용할 수 있나요?

기록 저장·조회·검색·계산은 기기에서 처리합니다. 클라우드 파일을 선택하거나 이메일로 문의하고 외부 앱에 파일을 공유할 때는 해당 서비스의 네트워크 연결이 필요할 수 있습니다.

### 어디에 기록이 저장되나요?

기록은 앱이 사용하는 기기 내 저장소에 저장됩니다. 운영자 서버에 자동 업로드되지 않습니다. 기기 변경이나 앱 제거에 대비해 JSON 백업 파일을 따로 보관해주세요. 운영체제 설정에 따라 OS 백업이 적용될 수 있지만, 앱 자체의 계정 동기화 기능은 아닙니다.

### 전체 기록을 백업하려면 어떻게 하나요?

1. 메인 오른쪽 위 설정을 엽니다.
2. **기록 백업·복원** → **백업 파일 만들기**를 선택합니다.
3. 운영체제 공유 창에서 ‘파일에 저장’ 등 원하는 보관 방법을 선택합니다.
4. 선택한 위치에 JSON 파일이 실제로 저장됐는지 확인합니다.

백업에는 보낸 마음과 받은 마음의 저장된 기록이 포함됩니다. 보기 설정과 저장하지 않은 예정 비용·장부 입력은 포함되지 않습니다. 최대 10,000건·10MB를 지원합니다. 파일은 앱에서 별도로 암호화하지 않으므로 안전한 위치에 보관해주세요.

### 백업을 복원하거나 다른 기기로 옮기려면 어떻게 하나요?

1. 독립 앱에서 만든 JSON 백업 파일을 사용할 기기에 준비합니다.
2. 설정 → **기록 백업·복원** → **백업 파일 선택**을 누릅니다.
3. 전체·추가·동일·내용이 다른 기존 기록 건수와 추가 금액을 확인합니다.
4. **추가 복원** 버튼을 누르면 없는 기록만 추가됩니다.

같은 기록 식별값을 가진 기록이 이미 있으면 현재 앱의 기록을 유지합니다. 백업 이후 수정한 내용을 덮어쓰지 않습니다. 같은 백업을 반복해서 복원해도 같은 식별값의 기록이 중복 저장되지 않습니다.

이름과 금액이 같아도 별도로 생성된 기록은 서로 다른 식별값을 가질 수 있습니다. 복원은 기기 간 자동 동기화 기능이 아닙니다.

### 백업 파일을 선택했는데 복원할 수 없어요.

이 독립 앱에서 만든 원본 JSON 백업인지 확인해주세요. 다른 앱의 파일, 수정되거나 손상된 파일, 지원하지 않는 버전, 허용된 크기·건수·값의 범위를 벗어난 파일은 복원할 수 없습니다.

파일 내용을 임의로 편집하지 말고, 원래 보관한 백업으로 다시 시도해주세요. 저장 공간도 확인해주세요. 복원 도중 저장에 실패하면 일부 기록만 추가되는 것을 막도록 일괄 작업을 취소하며, 다시 시도할 수 있습니다.

### CSV와 JSON 백업은 무엇이 다른가요?

**JSON 백업**은 저장된 전체 기록을 보관하고 복원하기 위한 파일입니다.

**CSV**는 축의금 장부에서 하객 내역을 가져오거나 선택한 날짜의 받은 축의금을 내보내는 파일입니다. 전체 기록 백업을 대신하지 않습니다. CSV를 입력 목록으로 가져온 뒤에는 저장 버튼을 눌러야 실제 기록이 됩니다.

### 앱을 껐다 켜니 입력 중인 예정 비용이나 장부가 사라졌어요.

저장하지 않은 예정 비용·장부 초안은 현재 앱 실행 중에만 유지됩니다. 운영체제가 앱을 종료하면 사라질 수 있습니다. 장부는 저장을 완료하고, 실제 기록은 필요할 때 별도로 백업해주세요.

### 기록이 안 보여요.

보낸/받은 모드, 검색어, 선택한 카테고리를 확인해주세요. 필터를 해제해도 없다면 실제로 저장했는지 확인합니다. 앱을 삭제하거나 기기 데이터를 지웠다면 별도로 보관한 JSON 백업 또는 운영체제 백업이 있는지 확인해주세요.

**백업을 확인하기 전에 앱을 삭제하거나 앱 데이터를 지우지 마세요.**

### 저장·파일 선택·공유가 실패해요.

기기의 저장 공간, 선택한 파일이 해당 기기에서 열리는지, 외부 저장소의 로그인·연결 상태를 확인해주세요. 앱을 다시 실행하기 전에는 저장하지 않은 입력이 있는지 확인합니다.

계속 실패하면 오류 문구와 실행 순서를 이메일로 알려주세요. 백업 파일이나 실제 사람의 기록 전체를 보내실 필요는 없습니다.

### 기록을 삭제하려면 어떻게 하나요?

- 개별 기록: 해당 기록을 열어 **삭제**를 선택합니다.
- 전체 기록: 메인 설정 → **모든 기록 삭제**에서 확인 후 삭제합니다.

전체 기록 삭제는 외부에 보관한 JSON·CSV 파일, 공유 상대가 받은 사본, OS 백업 사본까지 삭제하지 않습니다. 해당 위치에서 별도로 삭제해주세요. 기기 내 보기 설정과 저장하지 않은 초안은 기록과 별개입니다.

### 삭제한 기록이나 분실한 기기의 데이터를 복구해주나요?

운영자는 사용자 기록의 서버 사본을 보유하지 않아 원격 복구할 수 없습니다. 사용자가 보관한 JSON 백업 또는 운영체제의 백업이 있다면 해당 복원 방법을 사용해주세요.
