# iOS 입력 문구 초안

`ko/`의 텍스트 파일은 앱인토스 콘솔 원문을 그대로 복사했습니다. 등록 자료 전체와 이미지 순서는 [상위 안내](../README.md)를 참고하세요.

- `name.txt`: 얼마냈지요
- `english-name.txt`: Howmuchmoney — 영어 이름만 복사; 영어 소개 번역은 아직 없음
- `subtitle.txt`: 부제
- `description.txt`: 상세 설명
- `keywords.txt`: 검색 키워드, 쉼표 구분
- `support-email.txt`: 문의 이메일, App Store 지원 URL을 대신하는 항목은 아님

App Store Connect 제출/업로드나 fastlane 자동화 설정은 하지 않았습니다. 개인 정보 수집 여부는 독립 앱의 실제 코드와 사용 SDK에 맞춰 작성해야 합니다.
